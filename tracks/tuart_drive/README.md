# Tuart Drive

**Tier:** drive-anywhere. **Route:** `routes/tuart-drive.json`. **Build:** `out/tuart_drive.zip`.

The old Bussell Highway through Tuart Forest National Park, from near Wonnerup to Ludlow. Point to point, about 16 km, on 5 m LiDAR heights. Built with forest canopy read from the aerial (about 8,000 trees).
